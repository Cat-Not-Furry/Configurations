# eww

Widgets [ElKowars wacky widgets](https://github.com/elkowar/eww) — uso **opcional / legacy** en i3.

## Instalación

```bash
./I3/scripts/install-i3.sh
```

Destino: `~/.config/eww/`

## Requisitos

```bash
sudo pacman -S eww
```

## Uso

Scripts en `eww/scripts/` y referencias en `I3/i3-wm/conf.d/08-scripts.conf`.

Hyprland usa **Ignis** como shell principal; eww no es necesario en Wayland.
